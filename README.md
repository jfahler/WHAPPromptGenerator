# WHAP Prompt Generator

An interactive, randomized practice question generator for **AP World History (WHAP)**. Designed by a WHAP teacher to create dynamic, unpredictable practice activities for both educators and students preparing for the AP Exam.

[**Live Demo**](https://jfahler.github.io/WHAPPromptGenerator/) | [**GitHub Repository**](https://github.com/jfahler/WHAPPromptGenerator/tree/master)

---

## Features

* **Dynamic Question Generation:** Combines historical themes, time periods, and question stems to create unique prompts on the fly.
* **Exam-Aligned Skills:** Focuses on AP-style comparative, causation, and continuity-and-change-over-time (CCOT) reasoning skills.
* **Classroom-Ready:** Ideal for quick warm-ups, essay practice (DBQ/LEQ), class discussions, or review games.

## Usage

Simply launch the [live site](https://jfahler.github.io/WHAPPromptGenerator/), click the prompt generation button, and use the output for quick writes, essay outlines, or discussion hooks.

> **Note:** This tool generates prompts using randomized combinations. Due to the wide scope and variable logic, some combinations may yield unusual or unique results!
